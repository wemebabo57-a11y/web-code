我们的故事

从痛点出发，做一款纯粹的安全工具

市面上的安全软件越来越多，但用户体验却常常令人失望：体积动辄数百兆，安装过程捆绑一堆并不需要的附加组件；运行后驻留后台难以关闭，时不时弹出广告与推广窗口，把简单的「杀毒」做成了「全家桶」。我们想改变这种现状。

量盾的初衷很简单——做一款纯粹的安全工具。不臃肿、不打扰、不捆绑，把核心的扫描和查杀能力做到位，把选择权交还给用户。安装与卸载都干净利落，后台驻留可以自行开关，没有广告，也没有任何形式的强制推广。

技术上，量盾安全中心基于 ClamAV 开源反病毒引擎，融合自研病毒库与原生 ClamAV 病毒库进行已知病毒检测，并具备一定的未知威胁启发式识别能力。同时配合 HIPS 主动防御与内核驱动，构建多层次的本地防护体系，断网环境下仍可正常查杀。

项目目前持续维护中，版本迭代从未停止。我们欢迎每一位用户通过 GitHub 提交 Issue 与 PR，无论是问题反馈、规则补充还是代码贡献，都能让量盾变得更好。安全软件不应是黑箱，开放与透明才是它的底色。

核心价值观

我们坚持的三件事

轻量纯粹

安装包体积极小，不捆绑任何附加软件，不驻留不必要的后台进程。安装与卸载都干净利落，把系统资源还给用户。

本地优先

引擎完全本地运行，扫描与查杀无需依赖云端。断网环境下仍可正常工作，仅在更新病毒库时需要联网，隐私数据不离开设备。

开放透明

源代码在 GitHub 公开，欢迎社区监督与贡献。每一行代码都可被审视，每一次更新都有迹可循，安全不该是黑箱。

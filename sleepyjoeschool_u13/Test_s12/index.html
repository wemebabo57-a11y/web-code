合谋与背叛的博弈

1. 什么是合谋？

两家寡头公司通过秘密协议，共同把价格定在比竞争水平更高的水平，或者直接瓜分市场，以实现最大利润。这在经济学里叫“卡特尔”，是非法的，所以它们只能暗中进行。

2. 什么是背叛？

背叛就是其中一家公司偷偷违约，通过降价或增加产量，来抢走对方的市场份额，从而获得比合谋时更高的利润。

3. 为什么合谋总是不稳定的？

我们可以用一个简单的算式来理解这个“囚徒困境”。

假设只有A公司和B公司，它们都面临两个选择：合谋（保持高价） 或 背叛（降价抢市场）。

  • 如果两家都合谋：每家都能拿到高利润，比如各赚100万。
  • 如果一家背叛，一家合谋：背叛的公司会抢走大量市场，赚得盆满钵满，比如赚150万；而守约的公司则会损失惨重，只赚20万。
  • 如果两家都背叛：市场就会回到类似完全竞争的状态，价格战打起来，大家谁也赚不到大钱，比如各赚50万。

我们把这个情况做成一个简单的表格：

| A公司 \ B公司 | 合谋 | 背叛 |

| :--- | :--- | :--- |

| 合谋 | A: 100万, B: 100万 | A: 20万, B: 150万 |

| 背叛 | A: 150万, B: 20万 | A: 50万, B: 50万 |

现在我们来分析A公司的最佳策略：

  • 如果B公司选择合谋：A公司选择合谋能赚100万，选择背叛能赚150万。所以A公司会选背叛。
  • 如果B公司选择背叛：A公司选择合谋只能赚20万，选择背叛能赚50万。所以A公司还是会选背叛。

你看，不管B公司怎么做，A公司最理性的选择都是“背叛”。同理，B公司也会得出一样的结论。所以，这个博弈的唯一稳定结果就是双方都选择背叛，最终各赚50万。

这个结果对两家公司来说，都比合谋时赚得少，但却是它们无法摆脱的“囚徒困境”。
